# 🏴‍☠️ Enies Lobby Simulation System

> Bài tập lớn môn học **Kỹ thuật Lập trình** - Mô phỏng hệ thống chiến đấu dựa trên cốt truyện One Piece.

## 📖 Giới thiệu

**Enies Lobby** là một hệ thống mô phỏng chiến đấu (simulated battle system) được phát triển hoàn toàn bằng C++. Lấy cảm hứng từ arc giải cứu nổi tiếng trong bộ truyện _One Piece_, dự án tập trung vào việc quản lý trạng thái phức tạp của các thực thể, xử lý logic tương tác và mô phỏng các cơ chế chiến đấu.

Dự án này được xây dựng nhằm mục đích ứng dụng các cấu trúc dữ liệu, thuật toán và logic lập trình C++ để giải quyết các bài toán hệ thống, đồng thời rèn luyện kỹ năng phân tích, gỡ lỗi và tối ưu hóa mã nguồn để vượt qua các bộ test case khắt khe.

## ✨ Tính năng chính

- **Quản lý thực thể:** Khởi tạo và theo dõi cập nhật chỉ số, trạng thái của các nhân vật và hệ thống công trình (buildings).
- **Mô phỏng chiến đấu:** Xử lý logic combat, tính toán kết quả tương tác và kiểm soát vòng đời của các đối tượng trong trận chiến.
- **Hệ thống nhiệm vụ:** Quản lý tiến trình và đánh giá mức độ hoàn thành các nhiệm vụ (mission objectives) dựa trên bộ quy tắc định sẵn.
- **Kiến trúc mã nguồn:** Tổ chức source code module hóa, phân tách rõ ràng giữa định nghĩa (`eniesLobby.h`) và triển khai logic (`eniesLobby.cpp`).

## 🛠️ Công nghệ sử dụng

- **Ngôn ngữ:** C++ (Standard C++)
- **Môi trường:** Terminal / Command Prompt
- **Trình biên dịch:** Hỗ trợ GCC, Clang, MSVC
